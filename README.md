# 制作サイトのタイトル
- 値切りの虎 弐

## 1. 制作サイトの説明
- 浪速の交渉人 まっちゃんを相手に、なるべく安い金額で商品購入するゲームです。

## 2. 工夫した点・こだわった点
- 前回の課題に、商品と相場金額のランダム性を加えました。
- 七福堂とまっちゃんのビジュアルを作成しました。

## 3. 難しかった点・次回トライしたいこと（または機能）
- まっちゃんの表情を金額に応じて変化させたかったのですが、エラーで標準表情のままです。解決したい
- HTML/cssは今回はAIに完全お任せしています。JavaScriptの理解に重点を置きましたが、まだ未理解の部分も残っています。
- ゲーム性は微妙で、破綻している所もあります

## 4. 備考（感想、シェアしたいこと等なんでも）
- 動くゲームを作ることと、面白いゲームを作ることは、全く別物だと思いました。技術的な基礎は前提として、ゲームにしろSaaSにしろ、いかにユーザ目線で価値創出できるか、卒業制作に向けて念頭に置き頑張りたいです。
